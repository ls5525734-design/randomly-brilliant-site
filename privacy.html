Privacy Policy

Effective date: 26 October 2026

This policy explains what data Randomly Brilliant Uploader (the "Tool") handles. The Tool is operated by the owner of the Randomly Brilliant channel (the "Operator", "we"), who is the data controller, and is used only with TikTok accounts the Operator owns.

In short: the Tool keeps only what it needs to upload the channel's videos to its own TikTok account. Everything stays on the Operator's computer. Nothing is sold, shared for advertising or sent anywhere except TikTok.

1. Data we receive from TikTok

When the account owner authorizes the Tool through TikTok Login Kit, TikTok returns:

  • an access token and a refresh token, with their expiry dates;
  • the account's open_id (an app-specific identifier) and the list of permissions granted (for example user.info.basic and video.upload).

When the Tool uploads a video, TikTok returns a publish ID, the upload status and, once a video is public, its post ID. If direct posting is ever enabled, TikTok also returns the account's username, display name and available privacy options so that the owner's choices can be checked; only the username is kept, to build the link to the published video.

The Tool does not request or store messages, followers, contacts, analytics, location, or the profile data of anyone else.

2. Data we send to TikTok

The video files produced by Randomly Brilliant and, if direct posting is used, their caption, cover frame and the settings the owner chose. The Tool sends these only to TikTok's official API at open.tiktokapis.com.

3. Why we use it

Only to upload the channel's own videos to its own TikTok account, to check that each upload finished, and to avoid sending the same video twice. The legal basis is the Operator's legitimate interest in distributing its own content and the account owner's consent given through TikTok's authorization screen.

4. Where it is stored

  • Tokens are stored only on the Operator's computer, in the Windows user profile, outside the project folder. They are never written to logs.
  • A local operations log records which video was sent, when, its publish ID, post ID and status. It contains no tokens or passwords.
  • There is no server and no cloud database. The Tool uses no analytics, tracking or advertising services.

5. How long we keep it

  • Tokens: until access is revoked or they expire. TikTok refresh tokens last up to 365 days.
  • Upload records: for as long as the channel needs a history of what it has published. The Operator can delete them at any time.

6. Sharing

We do not sell, rent or share this data with anyone. The only recipient is TikTok, as described above.

7. Your rights and how to delete data

  • Withdraw access at any time from the app permissions section of your TikTok settings. The Tool can also revoke its token itself, and the local token file is deleted when it does.
  • You may ask us for access to, correction of or deletion of any data about you, or object to its use, by writing to the address below. We reply within one month.
  • If you are in the European Economic Area, you also have the right to complain to your data protection authority.

8. This website

These pages are static. They set no cookies and load no third-party scripts or fonts. They are hosted on GitHub Pages; GitHub may process technical data such as IP addresses to serve and secure the site, as described in the GitHub Privacy Statement.

9. Children

The Tool is not intended for children and is used only by the Operator.
